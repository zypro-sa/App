# تطبيق المساعد الشخصي (Flutter)

## التشغيل لأول مرة

يتطلب [Flutter SDK](https://docs.flutter.dev/get-started/install) (الإصدار 3.27 أو أحدث).

```bash
cd app
# إنشاء مجلدات المنصات (android / ios) دون المساس بالكود الموجود
flutter create . --org sa.zypro --project-name personal_assistant --platforms android,ios
flutter pub get
flutter run
```

الاتصال بمشروع Supabase مضبوط في `lib/core/config.dart`.

## نسخة الويب (للآيفون)
تُبنى وتُنشر تلقائيًا على GitHub Pages مع كل دمج في `main`:
**https://zypro-sa.github.io/App/**

على الآيفون: افتح الرابط في Safari ← زر المشاركة ← **إضافة إلى الشاشة الرئيسية**، فيعمل كتطبيق بأيقونته وبدون شريط المتصفح.

## أول دخول
1. افتح التطبيق واختر **أنشئ حسابًا**.
2. أول حساب يُنشأ يصبح **المالك** تلقائيًا.
3. إن كان تأكيد البريد مفعّلًا في Supabase، افتح بريدك وأكّد الحساب ثم سجّل الدخول.
   (للتجربة السريعة يمكن إيقافه من Supabase › Authentication › Sign In / Providers › Email › Confirm email.)

## هيكل الكود

```
lib/
├── main.dart                  نقطة البداية
├── core/
│   ├── config.dart            رابط ومفتاح Supabase
│   ├── theme.dart             الألوان والخط (IBM Plex Sans Arabic)
│   ├── router.dart            التنقل + الشريط السفلي + زر الإضافة
│   └── formatters.dart        تنسيق التواريخ بالعربية
├── data/
│   ├── models.dart            نماذج البيانات
│   └── repository.dart        الاتصال بقاعدة البيانات + مزوّدات Riverpod
├── widgets/common.dart        عناصر مشتركة (بطاقات، شارات، مربع المهمة…)
└── features/
    ├── auth/                  تسجيل الدخول
    ├── home/                  ١ لوحة اليوم
    ├── requests/              ٢ الطلبات
    ├── tasks/                 ٣ المهام
    ├── meetings/              ٤ الاجتماعات (+ المحضر)
    ├── clients/               ٥ العملاء وملف العميل
    ├── followups/             ٦ المتابعات
    ├── quick_add/             ٧ الإضافة السريعة
    └── more/                  ٨ المزيد
```

## ما يعمل في هذه النسخة
- تسجيل الدخول وإنشاء الحساب، مع صلاحيات المالك والمدير والموظف من قاعدة البيانات.
- لوحة اليوم ببيانات حقيقية: المؤشرات، الاجتماع القادم، مهام اليوم، المتابعات.
- الطلبات مع التصفية حسب الحالة وإبراز المتأخر.
- المهام: «مهامي» و«المُسندة للفريق»، مجمّعة زمنيًا، مع الإنجاز بضغطة.
- الاجتماعات: شريط الأسبوع، الجدول الزمني، جدول الأعمال، كتابة المحضر.
- العملاء: القائمة، الإضافة، ملف العميل بالمؤشرات والسجل.
- المتابعات: تم، تأجيل، تحويل إلى مهمة.
- الإضافة السريعة: مهمة، طلب، اجتماع، متابعة، ملاحظة.

## المرحلة القادمة
- تحويل قرارات الاجتماع إلى مهام.
- المشاريع، المالية، الملاحظات، التقارير.
- الإشعارات على الجوال، والإدخال الصوتي، وربط التقويم.
