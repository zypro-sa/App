# المساعد الشخصي (App)

تطبيق جوال يعمل كمساعد شخصي لمالك شركة خدمات وحلول أعمال: يجمع الطلبات والمهام والاجتماعات والعملاء والمتابعات في مكان واحد، حتى لا يضيع أي موعد أو وعد أو فرصة.

> Personal assistant mobile app for managing requests, tasks, meetings and clients.

---

## الفكرة

صاحب الشركة يتعامل يوميًا مع طلبات عملاء، ومهام له ولفريقه، واجتماعات، وعروض أسعار تنتظر الرد. هذه الأمور تتوزع عادة بين البريد والواتساب والتقويم والذاكرة. التطبيق يجمعها في واجهة واحدة، ويربطها ببعضها: الاجتماع مرتبط بالعميل، والعميل مرتبط بطلباته ومهامه وفواتيره.

## التبويبات الرئيسية

| # | التبويب | الغرض |
|---|---------|-------|
| 1 | **لوحة اليوم** | ملخص اليوم: الاجتماعات، المهام العاجلة، الطلبات المتأخرة، والتنبيهات |
| 2 | **الطلبات** | استقبال طلبات العملاء ومتابعتها من الاستلام حتى الإغلاق (الحالة، الأولوية، المسؤول، الموعد النهائي) |
| 3 | **المهام** | مهامي الشخصية والمهام المُسندة للفريق، بعرض قائمة أو لوحة |
| 4 | **الاجتماعات** | التقويم، جدول الأعمال، المحضر، وتحويل القرارات إلى مهام |
| 5 | **العملاء** | ملف لكل عميل: التواصل، السجل، العقود، الطلبات المرتبطة |
| 6 | **المشاريع** | الأعمال الكبيرة التي تجمع عدة طلبات ومهام، مع نسبة الإنجاز والمراحل |
| 7 | **المتابعات** | ما وعدتُ به، وما أنتظره من الآخرين، وعروض الأسعار المعلّقة |
| 8 | **المالية المختصرة** | عروض الأسعار، الفواتير المستحقة، والمدفوعات المتأخرة |
| 9 | **الملاحظات** | تدوين سريع للأفكار والمكالمات، مع تحويل أي ملاحظة إلى مهمة |
| 10 | **التقارير** | أداء الأسبوع والشهر: الطلبات المنجزة، زمن الإنجاز، أداء الفريق |

### عناصر مشتركة في كل التطبيق
- **بحث شامل** في كل البيانات من مكان واحد.
- **إضافة سريعة** بزر واحد (مهمة، طلب، اجتماع، متابعة، ملاحظة)، مع إدخال صوتي واستخراج الموعد والعميل من النص.
- **ربط بين العناصر** (عميل ← طلبات ← مهام ← اجتماعات ← فواتير).
- **إشعارات ذكية** للمواعيد النهائية والمتابعات المتأخرة.

## هيكل الواجهة (الجوال)

شريط تنقل سفلي بخمسة تبويبات، وزر «+» ثابت للإضافة السريعة:

```
[ اليوم ]  [ الطلبات ]  [ المهام ]  [ الاجتماعات ]  [ المزيد ]
```

تبويب **المزيد** يضم: العملاء، المشاريع، المتابعات، المالية، الملاحظات، التقارير، والإعدادات.

### الشاشات في النموذج المبدئي
1. **لوحة اليوم:** تحية، بحث، ثلاثة مؤشرات سريعة، بطاقة الاجتماع القادم، مهام اليوم، المتابعات.
2. **الطلبات:** تصفية حسب الحالة (جديد، قيد التنفيذ، بانتظار العميل، مغلق)، وبطاقات فيها نسبة الإنجاز والمسؤول.
3. **المهام:** «مهامي» و«المُسندة للفريق»، مجمّعة حسب: متأخرة، اليوم، هذا الأسبوع.
4. **الاجتماعات:** شريط أيام الأسبوع، جدول زمني، جدول الأعمال، المحضر، وتحويل القرارات لمهام.
5. **ملف العميل:** أزرار تواصل، مؤشرات (الطلبات، قيمة العقود، المستحق)، وسجل التعامل.
6. **المتابعات:** وعدتُ بها، أنتظرها، عروض الأسعار، واقتراحات تذكير ذكية.
7. **إضافة سريعة:** نافذة سفلية لاختيار النوع وإدخال التفاصيل.
8. **المزيد:** بقية الأقسام، ملخص الأسبوع، والإعدادات.
